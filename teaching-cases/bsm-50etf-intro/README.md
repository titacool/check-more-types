# 教学案例：一张上证 50ETF 认购期权值多少钱？

**难度**：入门  
**模型**：Black-Scholes-Merton（带连续股息率的欧式期权闭式解）  
**数据接口**：akshare  
**适合**：已经会写 Python 函数、会用 pandas 看一张表，刚学完认购期权和 BSM 公式的同学

这个案例不要求推导公式，也不要求计算隐含波动率。要完成的是一件具体的事：用公开行情给一张真实的上证 50ETF 认购期权算出理论价，再判断它的市场最新价相对模型是偏贵还是偏便宜。

参考答案是可运行的 Python 程序，在 [`solution/bsm_50etf.py`](solution/bsm_50etf.py)。请先独立完成，再对照。

## 1. 实际问题

你在券商衍生品部实习。收盘后，导师留下一个入门任务：

> 上证 50ETF 期权是欧式期权，可以用 Black-Scholes-Merton 模型。请选剩余不少于 7 个自然日的最近到期月份，在里面找最接近平值的一张认购合约。波动率用过去一年的历史波动率，利率用剩余期限最接近的 Shibor，股息率按“到期前会不会遇到下一次分红”来定。算出理论价，和行情最新价比一比，用几句话说明差价可能来自哪里。不要把它写成买卖建议。

做完后交一张参数表和一段结论。参数是标的价格 `S`、行权价 `K`、期限 `T`、连续复利 `r`、连续股息率 `q`、历史波动率 `σ`，再加上合约代码、市场价、理论价和差额。

价格单位是**元/份**，和交易所报价一致。一张合约对应 10000 份，把每份差额乘以 10000，就是一张合约差多少钱。

## 2. 先把公式写对

记 `N(x)` 为标准正态分布函数。Merton 模型比不含股息的 Black-Scholes 多一个连续股息率 `q`：

```text
d1 = [ln(S / K) + (r - q + σ² / 2) * T] / (σ * sqrt(T))
d2 = d1 - σ * sqrt(T)

认购 C = S * exp(-q * T) * N(d1) - K * exp(-r * T) * N(d2)
认沽 P = K * exp(-r * T) * N(-d2) - S * exp(-q * T) * N(-d1)
认购 Delta = exp(-q * T) * N(d1)
```

`N(x)` 可以用标准库里的误差函数：

```python
import math

def norm_cdf(x: float) -> float:
    return 0.5 * (1.0 + math.erf(x / math.sqrt(2.0)))
```

先不要接行情。用下面两组数字检查函数，四位小数要对上。

| 输入 | d1 | d2 | 认购 | 认沽 | 认购 Delta |
| --- | --- | --- | --- | --- | --- |
| `S=K=100, T=1, r=0.05, σ=0.20, q=0` | 0.3500 | 0.1500 | 10.4506 | 5.5735 | 0.6368 |
| 同上，但 `q=0.02` | 0.2500 | 0.0500 | 9.2270 | 6.3301 | 0.5869 |

第二组用来确认 `q` 真的写进了公式。`q` 变大时，认购变便宜，认沽变贵。

还可以检查平价关系。模型价格应满足：

```text
C - P = S * exp(-q * T) - K * exp(-r * T)
```

## 3. 六个输入怎么取

数据都通过 akshare 取。下面这些函数名和参数是接口约定，计算规则是本案例的约定。

| 用途 | akshare 函数 | 参数 |
| --- | --- | --- |
| 到期月份 | `option_sse_list_sina` | `symbol="50ETF"`, `exchange="null"` |
| 到期日 | `option_sse_expire_day_sina` | `trade_date` 为上表返回的月份，`symbol="50ETF"`, `exchange="null"` |
| 期权行情 | `option_finance_board` | `symbol="华夏上证50ETF期权"`, `end_month` 为月份的后四位 |
| 标的现价 | `option_sse_underlying_spot_price_sina` | `symbol="sh510050"` |
| 历史价格 | `fund_etf_hist_em` | `symbol="510050"`, `period="daily"`, `adjust="qfq"` |
| 分红 | `fund_etf_dividend_sina` | `symbol="sh510050"` |
| 利率 | `macro_china_shibor_all` | 无参数 |

几个容易写错的地方：

- 月份列表里是 `202610` 这种 6 位数。`option_finance_board` 的 `end_month` 要传 `2610`。
- 到期日接口返回 `(到期日, 剩余天数)`。剩余天数是相对调用当天的，可能和行情所属交易日不一致。期限要用**到期日减标的行情日期**，再除以 365。
- 合约代码里的 `C` 是认购，`P` 是认沽，例如 `510050C2610M02900`。
- 标的价格 `S` 用“最近成交价”。权利金用“当前价”；当前价为 0 时，改用“前结价”。
- 历史价格用前复权，只用来算收益率。`S` 仍然用没有复权的成交价，因为行权价和期权报价都对着这个价格。

### 选哪一张合约

1. 列出全部到期月份和到期日。
2. 去掉距离估值日不足 7 个自然日的月份，再取最近的一个。
3. 在这个月份的认购合约里，取 `|K - S|` 最小的一张。距离相同就取行权价更低的一张。

### 历史波动率

取估值日及以前的前复权收盘价，计算对数收益率 `ln(P_t / P_{t-1})`。用最近 **252** 个收益率的样本标准差（分母是 `n - 1`），再乘以 `sqrt(252)`：

```text
σ = stdev(最近 252 个对数收益率) * sqrt(252)
```

### 无风险利率

Shibor 表里的“定价”列是年化百分比，`1.35` 表示 1.35%。按剩余自然日选择最接近的一档：

| 期限 | 列名 | 代表天数 |
| --- | --- | --- |
| O/N | `O/N-定价` | 1 |
| 1W | `1W-定价` | 7 |
| 2W | `2W-定价` | 14 |
| 1M | `1M-定价` | 30 |
| 3M | `3M-定价` | 90 |
| 6M | `6M-定价` | 180 |
| 9M | `9M-定价` | 270 |
| 1Y | `1Y-定价` | 365 |

用这一列最新的一行。连续复利是：

```text
r = ln(1 + 报价 / 100)
```

### 连续股息率

50ETF 大约一年现金分红一次，不是每天均匀分红。Merton 模型里的 `q` 按下面的入门规则处理：

1. 累计分红前后相减，得到最近一次现金分红 `D`。最近一行日期就是最近一次除息日。
2. 假定月和日不变，推出严格晚于估值日的下一次除息日。
3. 下一次除息日晚于期权到期日：到期前拿不到这笔分红，`q = 0`。
4. 下一次除息日不晚于到期日：把这一笔分红折进剩余期限，

```text
q = ln(S / (S - D)) / T
```

`q = 0` 也是一个认真做出的输入，不是把股息率忘了。

## 4. 要交的结果

1. 公式自检：两组教科书数字，打印到四位小数。
2. 真实合约的参数表：估值日、合约代码、到期日、`S`、`K`、`T`、`r`、`q`、`σ`，以及每个参数对应的原始数据（用了哪一档 Shibor、最近一次分红是多少、下一次除息日是哪一天）。
3. 认购理论价、市场最新价、二者之差（元/份），以及乘以 10000 后的一张合约差额。
4. 一段结论，说明按这个历史波动率看，市场价偏贵还是偏便宜，并点出至少两个模型输入上的近似。结尾写明这不是交易建议。

选做：

- 用同一行权价再算认沽理论价，并检查模型平价残差是否接近 0。
- 计算认购 Delta。用一句话说明：标的上涨 0.01 元时，一张合约的权利金大约变动多少。
- 用市场认购价和市场认沽价再算一次平价残差，解释它为什么不像模型那样接近 0。

## 5. 思考题

不必写进程序，用自己的话回答即可。

1. 算波动率用前复权价格，`S` 却用未复权成交价。这两件事为什么不矛盾？
2. `σ` 按 252 个交易日年化，`T` 却用自然日除以 365。入门作业里可以同时这样用。如果以后要做得更严密，问题出在哪里？
3. 把本该为 0 的 `q` 改成一个正数，认购理论价会变高还是变低？
4. 50ETF 期权是欧式。如果标的换成可以提前行权的美式认沽，这个闭式解还会不会刚好是它的价格？
