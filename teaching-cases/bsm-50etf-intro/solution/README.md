# 参考答案

[`bsm_50etf.py`](bsm_50etf.py) 就是这份案例的参考答案。它完成任务书里的全部必做和选做：公式自检、读取 akshare 行情、计算六个输入、给最接近平值的认购合约定价，并与市场最新价比较。

在上一级目录安装依赖后运行：

```bash
python solution/bsm_50etf.py --check-only
python solution/bsm_50etf.py
```

`--check-only` 只核对教科书数字，不访问网络。不带参数时会拉取当天（或最近一个交易日）的公开行情。市场价会变，程序里的选择规则不会变。

不访问行情的计算测试：

```bash
python -m unittest tests/test_bsm.py
```

## 思考题答案

1. 前复权是为了让除息日的价格跳空不要混进波动率。`S` 必须用真实成交价，因为行权价和期权报价都对着这个价格。
2. 两套数字用了两套日历：一个数交易日，一个数自然日。入门案例把它们分开写清楚。更严密的做法要把波动率和期限放进同一种计息习惯，否则不同期限的价格不好比较。
3. `q` 变大，认购理论价变低。预期分红越多，标的价格本身在到期前被分掉的部分越多。
4. 不会刚好相等。BSM 闭式解对应欧式期权。美式认沽可能提前行权，价格通常不低于同条件的欧式认沽，欧式公式常常偏低。
