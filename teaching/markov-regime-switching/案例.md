# 教学案例：沪深300现在处于哪种波动状态？

难度：入门。一次上机可以做完。

本案例训练的是「把模型用到一个具体问题上」，不是推导滤波方程。参考答案是可运行的 Python 程序：`参考答案/markov_regime_csi300.py`。

## 1. 要解决的问题

指数增强小组每周开一次风控例会。投资经理不要求预测明天涨跌，只要求助手准备半页备忘，回答三件事：

1. 截至样本最后一天，沪深300更接近「平稳」还是「动荡」？概率是多少？
2. 这两种状态一般各自持续多久？从一种换成另一种的概率有多大？
3. 如果动荡概率已经升高，把当天风险预算降到一半，波动和回撤会怎样变化？

价格图本身答不好这些问题。同是一段下跌，可能只是平稳状态里的普通回调，也可能是波动已经换挡。马尔可夫机制转换模型让数据自己分成两种状态，并给出处于每种状态的概率。

备忘是教学演示，不是投资建议。

## 2. 学完要能做到

- 用自己的话说明这里的「机制」和「马尔可夫」各指什么
- 用 akshare 取出沪深300日线，并算出对数收益率
- 读懂两状态模型的结果：两个波动、转移概率、期望持续期
- 分清滤波概率和平滑概率，知道哪个能用于当时的决策
- 用一条事先写好的规则做样本内对照，并如实写出它没有改善的指标
- 说明为什么这次对照还不是严格的样本外检验

## 3. 只用到这些概念

市场每个交易日处于两种状态之一。对数收益率由当天的状态决定：

```text
r_t = μ(S_t) + ε_t
ε_t ~ 正态分布(0, σ²(S_t))
```

`S_t` 是状态。两个状态各有自己的平均收益和方差。估计完成之前，不要把状态 0、状态 1 叫成牛市或熊市。程序会把方差较小的叫「平稳」，方差较大的叫「动荡」。

马尔可夫指的是：明天的状态只和今天的状态有关，和更早的路径无关。

```text
明天仍处于状态 i 的概率 = p_ii
状态 i 的期望持续期 = 1 / (1 - p_ii)    单位：交易日
```

期望持续期是「一段状态从头到尾平均有多长」，不是从今天起的倒计时。已经在平稳状态里走了很多天，也不会改变明天留下的概率。

两个容易混的概率：

| 名称 | 用到的数据 | 用来做什么 |
| --- | --- | --- |
| 滤波概率 | 当天及以前 | 站在当天做判断。仓位规则只能用它 |
| 平滑概率 | 全部样本 | 事后给历史行情涂色、复盘。不能拿去当时下单 |

样本最后一天没有「未来」，所以这一天的滤波概率和平滑概率相同。中间日期两者才会分开。

## 4. 数据

教学样本固定为 2016-01-01 至 2025-12-31，方便对答案。这段覆盖了 2016 年初的大幅波动、2018 年、2020 年春节后、2022 年和 2024 年初。

| 项目 | 约定 |
| --- | --- |
| 接口 | akshare 的 `index_zh_a_hist` |
| 代码 | `000300`（沪深300） |
| 频率 | 日线 |
| 估计用的收益 | 对数收益率 `ln(P_t) - ln(P_{t-1})` |
| 对照收益用 | 简单收益率，方便连乘 |

东方财富接口若失败，参考答案会改用 akshare 的 `stock_zh_index_daily`（新浪财经，代码 `sh000300`）。两个都是 akshare 的指数日线接口。

第一次下载时屏幕上会有一个进度条，大约一分钟，那是在取行情，不是模型在估计。模型本身很快。

第一行价格没有前一日，收益率会少一天。2016-01-04 是区间内的第一个交易日，第一个收益率出现在下一个交易日。这是正常的。

## 5. 模型怎么设

使用 `statsmodels` 的 `MarkovRegression`，只保留入门设定：

- `k_regimes=2`：两种状态
- `trend="c"`：每种状态有一个均值
- `switching_variance=True`：每种状态有一个方差
- 不加外生变量，也不加自回归项

估计方法是极大似然。这一步不用手推，要会读程序打印的摘要。重点看两行方差，以及转移概率 `p[0->0]`、`p[1->0]`。均值的 p 值如果大于 0.05，就不要把该状态说成显著的上涨或下跌。

年化时一年按 252 个交易日：

```text
年化收益 = 日均对数收益 × 252
年化波动 = sqrt(日方差 × 252)
```

## 6. 仓位规则

规则在看到收益之前写定，避免做完再挑阈值：

```text
若前一交易日「动荡」的滤波概率 ≥ 50%，则当日仓位 = 50%
否则当日仓位 = 100%
```

必须用前一天的概率。当天的滤波概率已经包含了当天的涨跌，拿来决定当天仓位会偷看结果。

对照时现金收益按 0，不计交易成本。参数是用全样本估计的，所以业绩只是样本内演示：滤波概率没有使用未来行情，但均值、方差和转移概率用到了后来的数据。这还不是样本外检验。

## 8. 思考题

1. 为什么要等估计结束后再命名，而不能事先规定状态 0 就是牛市？
2. 如果两个均值的 p 值都大于 0.05，这个模型主要识别的是什么？
3. 平滑概率把历史涂色很清楚，为什么不能直接用它生成「当时」的仓位？
4. 全样本估计的参数再套回同一段行情，还缺哪一步才叫样本外？
5. 把阈值改成 0.7，或者把降低后的仓位从 50% 改成 0，波动、回撤和收益哪个变化最大？改完用自己的话解释，不要只贴数字。
6. 一段慢跌如果多数日子的滤波概率都低于 50%，这条规则还能不能把它识别成动荡？这说明模型管不管「所有下跌」？

## 9. 评分时看什么

- 样本区间和两种收益率的用途正确
- 状态按估计出的方差命名，而不是把编号 0、1 硬说成牛熊
- 决策使用滞后的滤波概率
- 结论报告概率和持续期，并如实写出规则没有改善的指标
- 写明对照使用了全样本参数，不能当成实盘业绩
